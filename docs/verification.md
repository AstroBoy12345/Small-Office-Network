# Verification

All results below come from the finished lab.

## 1. VLANs and trunks

`show vlan brief` (SW1, SW2) – every port is in its planned VLAN, VLAN 1 has no ports, unused ports are in VLAN 666.

`show interfaces trunk` – SW1 Gi0/1, SW1 Gi0/2 and SW2 Gi0/1:

| Mode | Encapsulation | Status | Native VLAN | Allowed VLANs |
|---|---|---|---|---|
| on | 802.1q | trunking | 999 | 10,20,30,99,999 |

`show interfaces gig0/1 switchport` (SW1) – `Negotiation of Trunking: Off` confirms DTP is disabled.

## 2. Spanning Tree

`show spanning-tree vlan 10`

| Switch | Root ID | Bridge ID | Notes |
|---|---|---|---|
| SW1 | 4106 (own address) | 4106 (4096 + VLAN 10) | "This bridge is the root", all ports Desg FWD |
| SW2 | 4106 (SW1) | 8202 (8192 + VLAN 10) | Gi0/1 = Root port, cost 4 |

## 3. Inter-VLAN routing

`show ip interface brief` (R1-EDGE) – G0/1 and subinterfaces .10, .20, .30, .99, .999 are up/up with the gateway addresses.

## 4. DHCP

`show ip dhcp binding` (R1-EDGE)

| IP address | Client |
|---|---|
| 192.168.10.21 | Staff PC |
| 192.168.10.22 | Staff PC |
| 192.168.30.21 | Guest laptop |

The first leased address in every pool is .21, which confirms the exclusions (.1 – .20) work.

## 5. Internet access (PAT)

`show ip route` – `Gateway of last resort is 203.0.113.1`, `S* 0.0.0.0/0 via 203.0.113.1`.

`show ip nat translations` after browsing `www.example.com` from a staff PC and the guest laptop:

![NAT translations](../images/nat-translations.png)

- UDP 53 entries = DNS, TCP 80 entries = HTTP
- Staff (192.168.10.21) and guest (192.168.30.21) both appear as **203.0.113.2**, separated by port numbers
